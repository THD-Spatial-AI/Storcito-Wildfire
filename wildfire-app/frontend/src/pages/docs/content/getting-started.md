# Getting started

## Create an account

1. Open the app and choose **Sign Up**.
2. Enter your full name, email address and a password. The password needs at least 8 characters, an uppercase letter, a lowercase letter, a number and a special character.
3. Accept the Declaration of Consent and the Privacy Policy, then select **Create Account**.
4. Open the verification email and click the link. You can resend it from the sign-in page if it does not arrive. Check your spam folder too.

If you forget your password, choose **Forgot your password?** on the sign-in page and follow the email instructions.

## First sign-in

The first time you sign in, a short **setup wizard** asks for:

- your interface language,
- a default location for the weather widget,
- a default map location,
- your notification preferences.

You can skip it and change everything later in **Settings**.

After that, a **guided tour** walks you through the main screen. It is shown only once. You can restart it at any time from the **?** (Help) menu → **Restart tour**.

## Data & privacy

The base map is loaded from external tile providers (CARTO and OpenStreetMap). Before the map is shown, you are asked to accept the **Data & Privacy** terms, which explain what these providers receive (for example your IP address, browser type and the time of the request). If you decline, the map stays hidden until you accept from **Settings → Privacy & Terms**.

## The screen layout

**Top bar** — location search, weather, notifications and your profile.

**Left sidebar**, from top to bottom:

| Icon | Opens |
|---|---|
| Flame | **Wildfire Simulations** — your model dashboard |
| Globe | **Interactive map** |
| Arrows | **Model comparison** (managers and experts) |
| Layers | Base map picker |
| GitHub | The project's source code on GitHub |
| **?** Help | Documentation, Restart tour and Feedback |
| Grid | **Dashboard** (admin dashboard) |
| Your initial | Profile, Settings and Sign out |

The small number at the bottom of the sidebar is the app version. Include it when you report a problem.

## Languages

The interface is available in English, Czech, Dutch, French, Galician, German, Greek, Italian, Polish, Portuguese and Spanish. Change it in **Settings → General → Language**.
