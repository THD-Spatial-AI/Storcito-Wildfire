# Interactive map

The map is your starting point. By default it shows Galicia, and the base map reveals more detail as you zoom in. The map can be viewed without signing in. You need to sign in to create models.

## What the map shows

| Outline | Meaning |
|---|---|
| Grey lines | Roads and administrative boundaries from the selected base map |
| Dashed line | The area covered by wildfire data. Models can only be calculated inside it |
| Green area | Your latest model. Select it to open its results |

The **Map outlines** legend in the corner explains these at any time.

## Moving around

- **Drag** to pan, **scroll** to zoom.
- Use the zoom buttons, **Center map** and **Fit to extent** in the map controls.
- **Right-click and drag** to rotate. **Reset to top-down** straightens the view again.

## Searching

Type a place name or address into the search bar. You can also enter coordinates as `lat, lon` (for example `42.88, -8.54`) to jump straight to a point.

## Base maps

Open the **Layers** button in the sidebar and choose a base map. Your choice is remembered.

## Bookmarks

Use **Map bookmarks** to save the current view under a name and return to it later. Saved map locations are also listed in **Settings → General → Map Location** and sync to your account.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `+` / `-` | Zoom in / out |
| Arrow keys | Move the map |
| `N` | Start a new model |

Shortcuts are ignored while you are typing in a text field.
